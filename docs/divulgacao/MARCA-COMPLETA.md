# Marca completa · Resolva Jato

Na divulgação pública, nunca use só “Resolva”, “RJ” ou “Jato” como nome do produto.
Há várias marcas parecidas (Resolva Já, ResolveJá, Resolva AI, Resolva Marcas) e
ruído semântico com “jato”.

## Forma canônica

| Uso | Texto |
|---|---|
| Nome | `Resolva Jato` |
| Domínio | `resolvajato.com.br` |
| Primeira menção | Nome + domínio (ou link UTM) na mesma peça |
| Hashtag (se usar) | `#ResolvaJato` |

## Regras por canal

1. **WhatsApp / Stories / Status:** a primeira linha (ou o fechamento) traz
   `Resolva Jato`. O link já carrega o domínio.
2. **LinkedIn / Facebook / comunidades:** diga `Resolva Jato` antes do benefício.
   Evite abrir só com o nome da ferramenta (“Calculadora de rescisão…”) sem marca.
3. **Diretórios / PH / MicroSaaS:** campo Nome = `Resolva Jato` (nunca abreviação).
4. **Outreach / guest post:** assinatura `… do Resolva Jato (resolvajato.com.br)`.
5. **Bio Instagram / TikTok:** linha 1 = `Resolva Jato`.

## Anti-padrões

- “Resolva” sozinho
- “RJ” como marca (ok só em nomes de arquivo internos, ex.: `RJ_escuro_thumb`)
- Link sem nenhuma menção textual à marca na peça
- Confundir com Resolva Já / ResolveJá / Resolva AI

## Checklist rápido antes de publicar

- [ ] Aparece `Resolva Jato` no texto?
- [ ] Link aponta para `resolvajato.com.br` (com UTM)?
- [ ] Alguém que não conhece a marca entende o nome completo sem abrir o link?
